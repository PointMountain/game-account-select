# ADR 0004: 三款游戏共享当前证据门槛

状态：accepted，2026-10-05。用户授权将明日方舟改进扩展到其他游戏并提交推送。

绝区零、鸣潮、异环通过共享 evaluator 与 finalizer 核对逐字段来源和当前队伍适用性。游戏 skill 保留历史数值规则；公共层不编造新角色强度，也不把历史分解释为当前排名。当前版本由本轮画像记录，来源须满足同版本、同玩法、7天、独立作者与无冲突要求。

标准化输出保留 `source_listing`，finalizer 不信任已有 eligible 标记。缺关键字段或当前队伍主张时保留完整候选及缺口，主推荐只包含通过者。原始 fixture 与 validate 脚本保持不变，新增行为测试覆盖三款游戏的公开入口与报告链路。

字段核验提到 toolkit，明日方舟原导出路径保留兼容。三款游戏共享学习队列与修复清单；平台访问和浏览器操作矩阵保持原有职责。此次未更改平台能力，不以离线测试宣称最新行情或阵容已经核实。
