## 专属音擎本地表

专属音擎名称映射维护在 `references/signature-engines.json`。读取螃蟹/盼之详情页时，角色右上角角标不一定写成 `x+y`；若只显示 `x`，需要把页面 `S级音擎` / `S级武器` 名称清单与该 JSON 逐名匹配。匹配到某代理人的专属音擎时，可以确认该代理人有专武；只看到总 S 音擎数量或无法匹配名称时，保持“专武未确认”。

维护要求：

- 新增需要记录的代理人时，同步补充中文名、常见别名和专属音擎名。
- 名称别名只放能在平台页面或可靠资料中确认的写法，避免把泛用 S 音擎误算成专武。
- 平台 detail operation 应输出 `sWEngineNames`；标准化层应同步到 `game_assets.s_w_engine_names` 或 `game_assets.w_engines[].name`。

## 队伍判断

- 主 C/异常核心 + 击破/支援/防护 + 合适邦布/音擎，队伍价值高。
- 限定代理人带专属音擎明显加分。
- 孤立限定但无队友、无音擎、无资源，只能中等评分。
- 常驻高影画只有在能补齐强队定位时才加中低权重。

### 当前虚狩队伍知识

3.1 的当前虚狩名单为星见雅、仪玄、叶瞬光、蕾米埃尔。旧“三虚狩”规则仍用于解释历史挂牌，但缺蕾米埃尔的账号不得再标“全部虚狩”。账号价值不能只看核心是否齐全，还要看独立队伍：

- 星见雅队：当前优先按 `星见雅 + 浮波柚叶 + 南宫羽/莱卡恩/苍角` 判断。没有柚叶时，不得默认雅队完整；`雅柚柳`、`耀嘉音/妮可` 等旧口径或下位组合只能中置信解释。
- 叶瞬光队：当前优先按 `叶瞬光 + 照 + 耀嘉音/琉音` 判断。只有照+千夏时按旧口径或下位可玩处理，不算当前三虚狩硬条件完整。
- 仪玄队：当前优先按 `仪玄 + 卢西娅 + 橘福福/琉音` 判断。只有仪玄本体和专属音擎不能视作完整队。
- 蕾米埃尔队：优先按 `蕾米埃尔 + 维琳娜 + 异常站场/触发位` 判断，第三人可从简、柏妮思、薇薇安、月城柳、爱丽丝、格莉丝等已披露异常位核验。专武是高价值加分但非可玩硬门槛；M1/M2 是前段断点，M6 增加站场与收藏价值。
- 独立队检查时，每名辅助只能分配给一支队伍；旧三虚狩共享琉音/耀嘉音的陷阱在四虚狩版本更严重。

### 3.0–3.1 新供给事实

- 维琳娜：限定 S、风异常，是蕾米埃尔异常队的高优先级搭档；专属音擎为 `琳琅鎏心`。
- 蕾米埃尔：限定 S、流明异常、当前虚狩；专属音擎为 `空羽复归之诗`。
- 希格莉德：3.1 限定 S、冰强攻；专属音擎为 `骁骑礼赞`。未出现在挂牌时不影响蕾米埃尔队判断。
- 佩洛伊斯：法厄同剧情可得角色，其影画与专属音擎 `日冕遗蜕` 由 3.0 永久玩法供给。买号估值按进度资产而非限定卡池成本计算。

### 额外队伍与舒适度信号

- 直伤电队：按 `希希芙 + 席德/希德 + 耀嘉音/耀佳音` 检查。三人齐全可作为账号“玩得舒服”的加分项；希希芙或席德 0+1 也加分。耀嘉音/耀佳音 1+1 是加分项，0+0 也可用，不能压过三虚狩 2+1 和核心专武齐全的账号。
- 异放队：需要妄想天使三小只，当前买号语境按 `千夏 + 爱芮 + 南宫羽` 处理；缺任一位不能算异放队齐全。三小只最好都有专武；南宫羽专武最关键，缺南宫羽专武时战斗力和性价比都要明显降级。
- 薇薇安紊乱队：按 `薇薇安 + 紊乱/异常搭档` 检查，搭档可包括简、柏妮思、月城柳、爱丽丝、格莉丝等；有薇薇安 0+1 或搭档 0+1 时作为舒适度加分。
- 虚狩 2+1 是显著舒适度加分；三位虚狩都 2+1 时排序应优先。
- 非虚狩角色的 0+1 通常优先于 1+0，因为专武往往比单影画更影响机制、循环或输出下限；除非当前社区证据明确某角色关键影画更重要。
- 琉音机制特殊，是高价值辅助和舒适度信号；缺琉音不直接否决，但同价位有琉音应优先。

- 推荐文案若说“约 N 抽”，应写明来自字段折算还是卖家备注；不能把 `菲林底片` 当成单抽券。
