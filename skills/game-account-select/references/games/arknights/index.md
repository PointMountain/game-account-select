# 明日方舟

筛选数据：[game.json](game.json)（限定/联动名单、历史 apex/core、字段映射）。社区证据：[evidence.md](evidence.md)（2026-10-05，low）。平台操作见 `sites/<site>/operations/arknights-*.md`。

## 看什么（按用户本轮目标取舍）

- 收藏：限定、联动干员要逐个点名。获取类型以 [限定名单](data/limited-roster.json) 和 [联动名单](data/collab-roster.json) 为准，两份名单都是 2026-10-05 从 PRTS 核对的；皮肤只算收藏加分，不能顶替稀缺干员。
- 战力/推图：看社区推荐核心的精二、专精和模组，再看先锋、阻挡、物理输出、法术输出、治疗、控制六类职能是否齐全。超大杯很多但缺先锋、阻挡或治疗的号要降级。
- 资源：抽数 = (合成玉 + 源石 × 180) / 600 + 十连券 × 10 + 单抽券。龙门币和材料不算抽数。
- 风险：区服（官服/B服）、实名换绑、找回包赔、官方验号。

## 常见坑

- 博士等级、只给六星总数或精二总数而没有名单、标题写“全图鉴/毕业”却没有验号佐证，这类号都不能排第一。
- 平台详情通常只暴露精一/精二名单。专精和模组为 null 时按未知处理，不能推定“通常会练”。
- 螃蟹列表标题里的数量不等于已核实的逐人名单，详情核实前不能升级为完整名单。
- 盼之详情里的“精二六星数”不能覆盖标题的精二总数，两者分开记录。
- 斥罪是常驻干员，维什戴尔是限定干员（旧表曾写错）。
- 未养成的限定数量不能压过练度清楚的成熟阵容。
- `operator-value-map.json` 里的 meta_tier 是 2026-08-02 的历史快照，只能作为初筛参考。强度结论需要两条以上 7 天内的独立来源。
