# 鸣潮

筛选数据：[game.json](game.json)（高/中价值限定、常驻高命陷阱、星声、绑定风险词）。社区证据：[evidence.md](evidence.md)（2026-05-16 的历史快照）。中文名已于 2026-11-09 用两个平台的真实资产名核对；“仇远”尚未在平台上见到。

## 看什么

- 先判断五星角色是当前强势限定、可组成关键队伍的限定、有专武的核心，还是常驻/弱势角色。总黄数、五星数量、五星武器数量只能粗看资产规模。
- 队伍：爱莫林（爱弥斯 + 莫宁 + 琳奈）、卡千夏（卡提希娅 + 千咲 + 夏空）、日月守（今汐 + 月相辅助 + 守岸人）、奥古斯塔 + 尤诺、绯雪队。这些都是 2026-05-16 的社区口径，使用前需刷新。
- 专武要能明确归属到主 C 或关键位；命座只有在社区确认属于质变时才加分。
- 资源：星声、月相、浮金波纹、铸潮波纹、余波珊瑚。
- 风险：TAP、Wegame、PS5 绑定，换绑冷却，渠道服，找回包赔，官方验号。

## 常见坑

- 凌阳、卡卡罗、鉴心、安可等常驻角色高命，不能压过少量但当前高价值的限定核心。
- 资源号只适合追求未来抽卡弹性的用户；用户要成品时不能压过已成型的队伍。
- 盼之鸣潮页面正文的前 4000 字可能没有游戏名。runner 已改为从可见正文提取身份信号，不要再用截断摘要判断页面身份。
