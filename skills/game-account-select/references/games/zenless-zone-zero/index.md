# 绝区零

筛选数据：[game.json](game.json)（虚狩名单、限定 S、专武表、资源字段、邮箱/绑定风险词）。专武表：[signature-engines.json](data/signature-engines.json)。社区证据：[evidence.md](evidence.md)（2026-08-03 的历史快照）。

## 看什么

- 限定 S 代理人要具名，常驻 S 高影画不能当主价值。虚狩名单（3.1）是星见雅、仪玄、叶瞬光、蕾米埃尔；版本变化时刷新，缺蕾米埃尔不能叫“全部虚狩”。
- 专属音擎：资产卡角标 `x+y` 中 `+y` 是专武数量。只显示 `x` 时，用 `sWEngineNames` 和专武表逐名匹配；匹配不到才算“专武未确认”，不能用 S 音擎总数推断。
- 队伍要能独立成队，同一辅助不能重复分给两队。历史口径：雅 + 柚叶 + 南宫羽/莱卡恩/苍角；叶瞬光 + 照 + 耀嘉音/琉音；仪玄 + 卢西娅 + 橘福福/琉音；蕾米埃尔 + 维琳娜 + 异常位。
- 同价位下，非虚狩角色通常 `0+1` 优于 `1+0`；虚狩 `2+1` 是强加分；耀嘉音 `0+0` 也可用。
- 资源：抽数 = (菲林 + 菲林底片) / 160 + 加密母带 + 原装母带 + 邦布券。菲林底片不是抽卡券。
- 风险：邮箱未绑定 / 邮箱未实名出售风险低；邮箱实名出售需要人工确认；邮箱不出售风险高。另看 HoYoverse、PSN、TAP 绑定，以及 B服/渠道服。国际服要单独记录区域，不自动扣分。

## 常见坑

- 只写 S 数量或绳匠等级的号不能排第一。
- 佩洛伊斯及其专武来自永久玩法，不按限定卡池计算溢价。
- 螃蟹详情页“商品推荐”区的资产不能混入本商品；“满命X”按 X 6 影画解析。
- 盼之 ZZZ 列表入口是 `goodsList/275`。详情 URL 末尾的 `/6` 不是游戏 ID，误用 `goodsList/6` 会读到别的游戏。
- 盼之有时数值写在资源名前面（“248加密母带”），有时标签写在数量前面（“S级音擎3”）；解析器两种写法都支持，相邻的无关数字不能借用。
