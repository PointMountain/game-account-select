# 四款游戏的螃蟹与盼之双平台支持

## 变化

- 接通绝区零、鸣潮、异环在螃蟹的列表搜索和详情读取。支持矩阵现有 16 个已验证游戏操作，覆盖四款游戏、两个平台的列表与详情。
- 列表按游戏、价格区间和页码查询，正确将螃蟹价格从分转换为人民币元，并保留商品 ID 与来源链接。
- 绝区零详情使用 URL 的数字商品 ID，标题展示编号另存为 `productCode`；角色、音擎、皮肤按类别隔离。
- 鸣潮和异环保留具名角色、武器或弧盘、养成数值及来源；角色卡片缺失时读取明确的标题资产清单，未披露的养成保持未知。
- 商品推荐、访问动态与充值保障金额不作为主体资产或售价来源；错误游戏、商品 ID 不符、缺价或未注册操作均有回归反例。
- 更新三个游戏 skill、平台访问策略和 selector 状态机；实时回归改为每款游戏检查两平台，并生成包含两边候选的估值报告。
- 更新评估器中依赖旧支持范围的用例，保留未注册操作的拒绝检查，以及角色角标、音擎名称缺失的检查。
- 中英文 README 的游戏表与 Project Status 同步为四款游戏双平台支持。

## 实证与验证

- ego-browser 受控探索与普通查询链路均通过新增六个操作，外部 ego-ops 新增六份操作知识并通过知识校验。
- 绝区零、鸣潮、异环完成双平台列表、详情、估值、finalizer、报告门禁和 task-space 清理；修复旧门禁用例后，用同轮真实数据重放报告收尾并通过。
- 明日方舟原有双平台全栈回归通过。
- 螃蟹绝区零以 100–300 元、第二页进行价格与分页实测。
- 离线回归覆盖价格单位、范围、分页、去重、字符串 ID 精度、主体数据隔离、卡片分类、标题降级和操作能力校验。
- 本地运行证据位于 `.harness/pxb7-four-game-support/`；完整检查入口为 `npm run dev:check` 和 `npm run verify:skills`。
